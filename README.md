## Regras para quem editar o site ou os anúncios

1. Todo número ou promessa (preço, alunos formados, credenciamento) deve estar em `negocio.md`. Se não estiver lá, não publique.
2. O que o anúncio promete precisa aparecer na página de destino — inclusive a condição do preço (pagamento até o 5º dia útil).
3. Não prometa emprego garantido nem use depoimentos que não sejam reais.
